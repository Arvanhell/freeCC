How do let and const work ddifferently when it comes to variable declaration, assignment, and reassignment?

LESSON

When working with JS, you'll often declare variables to store data that you plan to use throughout your program.

In modern JavaScript, let and const are the preferred ways to declare variables, but they differ in how they handle value assignment and reassignment.

Difference is that if you assigned variable within let the value is can be updated later.

On the other hand, const is used to declare variables that are constant. Once you assign a value to a variable declared with const, you cannot reassign it.

This makes const ideal for values that you dont't want to change accidently during the execution of your program.

Trying to reassign a value to const variable will throw an error in your JavaScript console, as const variables are immutable once they are assigned.

Variables declared with const must be assigned a value at the time of declaration. If you try to declare a const variable without assigning it a value, you will get an error.
